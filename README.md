# Автозаполнение климатической характеристики (ИГМИ → шаблон)
Заполняет шаблонный документ на основе информации из предоставленного отчёта. 

LLM: ollama 
В настоящий момент тестирование проходит с использованием связки моделей bge-m3 (эмбеддинг-модель) + qwen3.6:35b
Парсинг: python-docx

Описание работы:
Система парсит .docx файл исходника в коллекцию, после векторизует полученный результат.
Тот же самый процесс происходит с шаблонным файлом.
Эти процессы проходят независимо друг от друга и разделяются на табличные и параграфовые представления для последующего формирования запроса к llm.

Далее, через косинусное сходство происходит нахождение наиболее релевантного куска данных, который и отправляется в промпт.

В качестве результата обработки данных llm формируется валидный (отказаустойчивый для блока парсера) JSON файл, который используется для расфасовки данных из исходника в шаблон. 

# Known issues
1. Не тестировалось кеширование.
2. Вероятна недетерменированность результата обработки llm.
3. Возможны ошибки парсинга (на основе ответа llm).
4. Возможно исключение на основе обрыва контекста (num_ctx не динамический)
